## Resumen del curso

Este curso introductorio enseña a estudiantes de secundaria a crear y personalizar una página web sencilla con **HTML y CSS**, desde la estructura y los elementos básicos hasta colores, bordes, imágenes y enlaces. El aprendizaje se organiza en ocho videos con demostraciones y actividades prácticas en **JSFiddle**, sin instalaciones.

- **Duración total:** 60 minutos (8 lecciones).
- **Público objetivo:** Estudiantes de 12 a 17 años sin experiencia previa.
- **Prerrequisitos:** Ninguno.
- **Herramientas necesarias:** Navegador web (Chrome, Firefox, Safari o Edge) y [JSFiddle](https://jsfiddle.net/).
- **Modalidad:** Videos breves, demostraciones paso a paso y prácticas individuales pausando el video.
- **Repositorio de código fuente:** [webdev-course-StackRoot
](https://github.com/StackRoot-1ASI0730-2620-8084/webdev-course-StackRoot.git).

> **Importante:** JSFiddle permite practicar en el navegador sin instalar programas. Algunas funciones para guardar o compartir proyectos pueden requerir iniciar sesión. Los enlaces precargados deben comprobarse antes de publicarlos.

## Secuencia de las lecciones

### Lección 1: ¿Qué es un sitio web? (3 minutos)

- **Descripción:** Descubre qué es un sitio web, cómo se comunica el navegador con un servidor y qué funciones cumplen HTML y CSS. Conoce JSFiddle y sus paneles de edición.
- **Enlace al video:** [Pendiente de agregar enlace de YouTube].
- **Conceptos clave:** URL, navegador, servidor, HTML como estructura y contenido, CSS como presentación; inspección de una página desde el navegador.
- **Práctica — Explorar un sitio web:** Cambia el texto de un título HTML y modifica el color de fondo con CSS; ejecuta cada cambio con **Run**.
- **Práctica**: [Clic para programar](https://jsfiddle.net/) 👈 **¡No necesitas registrarte!**


### Lección 2: Tu primera página: la estructura HTML (4 minutos)

- **Descripción:** Aprende qué son las etiquetas, los elementos y los atributos, y reconoce el esqueleto de una página HTML: `<!DOCTYPE html>`, `html`, `head`, `title` y `body`.
- **Enlace al video:** [Pendiente de agregar enlace de YouTube].
- **Conceptos clave:** Etiquetas de apertura y cierre, atributos como `lang`, títulos `<h1>`, párrafos `<p>` y sangría. En JSFiddle, el panel HTML representa el contenido del `body`.
- **Práctica — Mi primera página:** Escribe un título con un apodo inventado y dos párrafos; elimina temporalmente una etiqueta de cierre, observa el resultado y corrígela.
- **Práctica**: [Clic para programar](https://jsfiddle.net/) 👈 **¡No necesitas registrarte!**

### Lección 3: Títulos, párrafos y listas (3 minutos)

- **Descripción:** Organiza la información de una página sobre un pasatiempo mediante encabezados, párrafos, texto destacado y listas.
- **Enlace al video:** [Pendiente de agregar enlace de YouTube].
- **Conceptos clave:** Encabezados `<h1>` a `<h6>`, párrafos `<p>`, énfasis con `<strong>` y `<em>`, listas sin orden `<ul>`, listas ordenadas `<ol>` y elementos `<li>`.
- **Práctica — Mi pasatiempo favorito:** Crea un título principal, dos subtítulos, párrafos y una lista de tres razones; cambia una lista de viñetas por una numerada.
- **Práctica**: [Clic para programar](https://jsfiddle.net/) 👈 **¡No necesitas registrarte!**

### Lección 4: Imágenes y enlaces (2 minutos 25 segundos)

- **Descripción:** Enriquece tu página con imágenes y enlaces, cuidando la accesibilidad y la procedencia de los recursos.
- **Enlace al video:** [Pendiente de agregar enlace de YouTube].
- **Conceptos clave:** `<img>`, atributos `src`, `alt` y `width`; enlaces `<a>`, `href` y `target="_blank"`; texto descriptivo y uso responsable de imágenes.
- **Práctica — Imagen y enlace:** Agrega una imagen con descripción alternativa y ajusta su ancho; crea un enlace a [MDN Web Docs](https://developer.mozilla.org/es/) y prueba su funcionamiento.
- **Práctica**: [Clic para programar](https://jsfiddle.net/) 👈 **¡No necesitas registrarte!**

### Lección 5: Dale estilo con CSS (3 minutos 35 segundos) 

- **Descripción:** Aprende a escribir reglas CSS, utilizar selectores y personalizar el fondo, los títulos, los párrafos y las frases destacadas.
- **Enlace al video:** [Pendiente de agregar enlace de YouTube].
- **Conceptos clave:** Selector, propiedad y valor; llaves y punto y coma; `background-color`, `color`, `font-family`, `font-size`, `font-weight`; selectores de elemento y clase (`.destacado`).
- **Práctica — Estilo a mi página:** Cambia el fondo y la fuente, modifica los colores de los encabezados y crea una clase `destacado` para resaltar un párrafo.
- **Práctica**: [Clic para programar](https://jsfiddle.net/) 👈 **¡No necesitas registrarte!**

### Lección 6: Centrar, colores y bordes (3 minutos)

- **Descripción:** Aprende a centrar contenido y construir una tarjeta visual mediante el modelo de caja de CSS.
- **Enlace al video:** [Pendiente de agregar enlace de YouTube].
- **Conceptos clave:** `text-align`, `max-width`, `padding`, `border`, `border-radius`, `margin`, `background-color` y agrupación con `<div>`.
- **Práctica — Mi tarjeta:** Crea una tarjeta con un apodo y un pasatiempo, céntrala, añade un borde y esquinas redondeadas; prueba diferentes colores y radios.
- **Práctica**: [Clic para programar](https://jsfiddle.net/) 👈 **¡No necesitas registrarte!**

### Lección 7: Construye tu página de perfil (11 minutos 38 segundos)

- **Descripción:** Integra HTML y CSS para crear una página de perfil ficticio, comenzando con un boceto y terminando con una tarjeta personalizada.
- **Enlace al video:** [Pendiente de agregar enlace de YouTube].
- **Conceptos clave:** Estructura con `<div class="perfil">`, imagen, encabezados, párrafos, lista de gustos y enlace; estilos de fondo, tipografía, bordes, centrado e imagen circular con `border-radius: 50%`.
- **Proyecto final — Mi página de perfil:** Diseña un boceto, escribe el contenido HTML, aplica los estilos CSS y personaliza el apodo, los gustos, la imagen y los colores.
- **Privacidad:** Usa un apodo y datos ficticios o generales; no publiques nombre completo, colegio, dirección, teléfono ni fotografías personales.
- **Compartir:** Si está disponible, utiliza la función de guardar o compartir de JSFiddle; puede requerir iniciar sesión.

### Lección 8: Errores comunes y próximos pasos (2 minutos 42 segundos)

- **Descripción:** Identifica errores frecuentes en HTML y CSS, aprende a comprobar el código y conoce recursos para continuar practicando.
- **Enlace al video:** [Pendiente de agregar enlace de YouTube].
- **Conceptos clave:** Cierre de etiquetas, comillas en atributos, punto y coma y llaves de CSS, coincidencia de nombres de clase, texto `alt` y jerarquía de encabezados.
- **Práctica — Encuentra los errores:** Corrige una página con una etiqueta sin cerrar, atributos incompletos, una clase mal escrita y un error de sintaxis CSS; vuelve a ejecutar con **Run**.
- **Recursos para continuar:** [MDN Web Docs](https://developer.mozilla.org/es/) y [Validador HTML de W3C](https://validator.w3.org/).
- **Cuestionario final:** https://docs.google.com/forms/d/e/1FAIpQLSfX7Az0fbt6DxwovCDy7jvhhaJMbwd4bSQXy6rYgELKymm-Mg/viewform?usp=dialog
