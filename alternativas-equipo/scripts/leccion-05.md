# Lección 5: Dale estilo con CSS

## Objetivo de la práctica
Completa reglas de h1, p y .destacado; cambia colores y fuentes.

## Instrucciones para el estudiante
1. Abre https://jsfiddle.net/ en tu navegador.
2. Abre `starter-files/ejercicio-05/index.html` y copia **solo lo que está dentro de `<body>`** al panel HTML.
3. Copia el contenido de `starter-files/ejercicio-05/style.css` al panel CSS. No copies la etiqueta `<link>`.
4. Pulsa **Run** para ver el resultado.
5. Completa reglas de h1, p y .destacado; cambia colores y fuentes.
6. Vuelve a pulsar **Run** y comprueba los cambios.

## Resultado esperado
Solo el párrafo con clase destacado recibe ese estilo.

## Para quien imparte la lección
- Muestra primero el código inicial y explica los cambios uno por uno.
- Deja una pausa para que el estudiante pruebe por su cuenta.
- Compara el resultado con `completed-examples/ejercicio-05/` cuando esté disponible.
- No solicites nombres completos, colegio, dirección, teléfono ni fotos personales.

**Nota:** Esta guía complementa el guion audiovisual; no es un programa JavaScript.
