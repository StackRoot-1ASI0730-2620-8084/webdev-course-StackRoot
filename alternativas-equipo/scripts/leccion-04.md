# Lección 4: Imágenes y enlaces

## Objetivo de la práctica
Ajusta width a 200, revisa alt y modifica el texto del enlace a MDN.

## Instrucciones para el estudiante
1. Abre https://jsfiddle.net/ en tu navegador.
2. Abre `starter-files/ejercicio-04/index.html` y copia **solo lo que está dentro de `<body>`** al panel HTML.
3. Copia el contenido de `starter-files/ejercicio-04/style.css` al panel CSS. No copies la etiqueta `<link>`.
4. Pulsa **Run** para ver el resultado.
5. Ajusta width a 200, revisa alt y modifica el texto del enlace a MDN.
6. Vuelve a pulsar **Run** y comprueba los cambios.

## Resultado esperado
Imagen y enlace descriptivo funcionan.

## Para quien imparte la lección
- Muestra primero el código inicial y explica los cambios uno por uno.
- Deja una pausa para que el estudiante pruebe por su cuenta.
- Compara el resultado con `completed-examples/ejercicio-04/` cuando esté disponible.
- No solicites nombres completos, colegio, dirección, teléfono ni fotos personales.

**Nota:** Esta guía complementa el guion audiovisual; no es un programa JavaScript.
