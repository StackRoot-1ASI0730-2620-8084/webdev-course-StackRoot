# Lección 7: Construye tu página de perfil

## Objetivo de la práctica
Personaliza un perfil ficticio con imagen, lista, enlace y estilos.

## Instrucciones para el estudiante
1. Abre https://jsfiddle.net/ en tu navegador.
2. Abre `starter-files/perfil/index.html` y copia **solo lo que está dentro de `<body>`** al panel HTML.
3. Copia el contenido de `starter-files/perfil/style.css` al panel CSS. No copies la etiqueta `<link>`.
4. Pulsa **Run** para ver el resultado.
5. Personaliza un perfil ficticio con imagen, lista, enlace y estilos.
6. Vuelve a pulsar **Run** y comprueba los cambios.

## Resultado esperado
Perfil legible, sin datos personales reales.

## Para quien imparte la lección
- Muestra primero el código inicial y explica los cambios uno por uno.
- Deja una pausa para que el estudiante pruebe por su cuenta.
- Compara el resultado con `completed-examples/perfil/` cuando esté disponible.
- No solicites nombres completos, colegio, dirección, teléfono ni fotos personales.

**Nota:** Esta guía complementa el guion audiovisual; no es un programa JavaScript.
