# Lección 2: Mi primera página

## Objetivo de la práctica
Sustituye el apodo y escribe dos párrafos; comprueba la etiqueta de cierre.

## Instrucciones para el estudiante
1. Abre https://jsfiddle.net/ en tu navegador.
2. Abre `starter-files/ejercicio-02/index.html` y copia **solo lo que está dentro de `<body>`** al panel HTML.
3. Copia el contenido de `starter-files/ejercicio-02/style.css` al panel CSS. No copies la etiqueta `<link>`.
4. Pulsa **Run** para ver el resultado.
5. Sustituye el apodo y escribe dos párrafos; comprueba la etiqueta de cierre.
6. Vuelve a pulsar **Run** y comprueba los cambios.

## Resultado esperado
Un h1 y dos p se ven correctamente.

## Para quien imparte la lección
- Muestra primero el código inicial y explica los cambios uno por uno.
- Deja una pausa para que el estudiante pruebe por su cuenta.
- Compara el resultado con `completed-examples/ejercicio-02/` cuando esté disponible.
- No solicites nombres completos, colegio, dirección, teléfono ni fotos personales.

**Nota:** Esta guía complementa el guion audiovisual; no es un programa JavaScript.
